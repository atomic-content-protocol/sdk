# macOS Sandboxes

Daytona provides **macOS sandboxes** for AI agents that need a macOS operating system. A macOS sandbox is an isolated macOS environment that runs on dedicated Apple silicon hardware. Each sandbox runs on a Mac reserved for your account, with its own filesystem and desktop. Agents and developers can install software, run macOS applications and command-line tools, and control the desktop through Computer Use, VNC, and SSH.

macOS sandboxes are provided through the [use.computer ↗](https://use.computer) platform. You reserve a Mac, then create macOS sandboxes on it through the use.computer API with a use.computer API key. The Daytona SDKs, CLI, and API do not manage macOS sandboxes.

| **Term**             | **Description**                                                                   |
| -------------------- | --------------------------------------------------------------------------------- |
| **Sandbox**          | An isolated macOS environment on a reserved Mac, created on demand to run code.   |
| **Apple silicon**    | The Mac hardware that macOS sandboxes run on.                                     |
| **Reservation**      | A Mac reserved for your account. macOS sandboxes run on a reserved Mac.           |
| **API key**          | The use.computer API key. It is separate from your Daytona API key.               |

## Use cases

macOS sandboxes are used when the software, the build, or the task requires macOS.

- **Computer-use agents on macOS**: an agent operates macOS applications through screenshots and input events, for tasks that exist only in macOS software.
- **macOS-only software**: applications and command-line tools that run only on macOS run on a reserved Mac instead of on a developer's laptop.
- **Build and test on macOS**: Xcode builds, test suites, and scripts run on a clean macOS machine for each run, so results do not depend on leftover state.
- **macOS application automation**: scripts drive macOS applications and desktop interactions on real Apple silicon hardware.

## Create a macOS sandbox

Create a macOS sandbox on a reserved Mac.

1. Go to [use.computer ↗](https://use.computer/)
2. Obtain an API key
3. Reserve a Mac
4. Use the API key to create a macOS sandbox
5. See [use.computer API ↗](https://api.use.computer/openapi.yaml) for computer use, VNC, SSH, screenshots, and other macOS sandbox operations.


```bash
curl 'https://api.use.computer/v1/sandboxes' \
  --request POST \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer YOUR_USE_COMPUTER_API_KEY' \
  --data '{
  "type": "macos"
}'
```
