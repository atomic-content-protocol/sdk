# ACP Specification

The normative specification is published on the website and versioned with it:

- Overview: https://atomiccontentprotocol.org/getting-started/what-is-acp/
- ACO (Atomic Content Object): https://atomiccontentprotocol.org/spec/aco/
- Container: https://atomiccontentprotocol.org/spec/container/
- Collection: https://atomiccontentprotocol.org/spec/collection/
- Enrichment & Provenance: https://atomiccontentprotocol.org/spec/enrichment/
- Relationships: https://atomiccontentprotocol.org/spec/relationships/
- Access Model: https://atomiccontentprotocol.org/spec/access/

Source files live in [`apps/website/src/content/docs/spec/`](../apps/website/src/content/docs/spec/). The Zod schemas in [`packages/core/src/schema/`](../packages/core/src/schema/) are the reference implementation; a mismatch between the two is a bug.
